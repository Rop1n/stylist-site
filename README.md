# Александр Громов — Сайт-визитка мужского стилиста

Сайт-визитка для мужского стилиста классической одежды. Учебный проект (Фаза 1, Проект 1.1).

## Стек

- HTML5
- Tailwind CSS v4 (npm)
- Vanilla JS ES6+

## Секции

- **Hero** — фоновое фото с параллаксом, крупная типографика
- **Lookbook** — галерея работ с табами (smart casual / business-casual)
- **Услуги** — 4 карточки с glassmorphism эффектом
- **Отзывы** — 3 карточки клиентов
- **Форма записи** — модальное окно с отправкой через Formspree

## Запуск


```bash
npm install

```
```bash
npm run dev
```

Открыть `index.html` через Live Server.
